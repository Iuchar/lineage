# Родословные

Веб-приложение для работы с родословными из файлов GEDCOM. Каждый файл становится отдельным родом со своим деревом; между родами ставятся связки, по которым можно переходить из дерева в дерево.

Спроектирован интерфейс, выбран визуальный язык, работает прототип раскладки на настоящих данных. Приложение в работе: первый этап, каркас сервера и интерфейса.

## Что где лежит

| Папка | Содержимое |
|---|---|
| `*.ged` в корне | Исходные родословные: Гленн Уриск, Уинтерхоуп, О'Дувейн, Монад Кройве |
| `server/` | Сервер на Python: API, разбор GEDCOM, база |
| `web/` | Интерфейс на TypeScript: холст дерева, панели |
| `data/` | База и портреты, в git не попадают |
| `docs/` | Проектный документ, решения по дизайну, задачи |
| `prototype/` | Прототип раскладки дерева, по которому принимались решения |
| `mockups/` | Макеты, по которым принимались решения |

## Приложение

Нужны Python с менеджером [uv](https://docs.astral.sh/uv/) и Node.js — последний только для сборки интерфейса.

Запуск одной командой из корня проекта — соберёт интерфейс, если он устарел, и поднимет сервер на `http://127.0.0.1:8710`:

```bash
uv run --project server rodoslovnye
```

Загрузить файл новым родом — база создаётся в `data/rodoslovnye.sqlite3` при первой загрузке:

```bash
uv run --project server rodoslovnye import Gleann_Uruisg_tree.ged --name "Гленн Уриск"
```

Тесты сервера и интерфейса:

```bash
uv run --project server pytest
```

```bash
cd web && npm test
```

Раскладка дерева (`web/src/layout/`) сверена со стендом по координатам: эталон снят в десяти режимах и лежит в `web/src/layout/fixtures/stand-golden.json`. Если раскладка меняется намеренно, эталон переснимается вместе с решением в `docs/decisions.md`.

После изменения API на сервере — пересобрать типы интерфейса; после изменения разбора — тестовые роды:

```bash
cd web && npm run api
```

```bash
cd web && npm run fixtures
```

Разработка интерфейса с перезагрузкой на лету — сервер запущен командой выше, а во втором окне:

```bash
cd web && npm run dev
```

## Прототип

Открыть готовый файл: `prototype/build/stand.html` — самодостаточная страница, работает двойным кликом, без сервера.

Пересобрать после правок шаблона:

```bash
cd prototype/src && python build_stand.py
```

Перегнать GEDCOM в данные прототипа:

```bash
cd prototype/src && python ged2json.py ../../Monadh_Croibhe_tree.ged ../data/monadh-slim.json
```

| Файл | Назначение |
|---|---|
| `prototype/src/stand_template.html` | Шаблон стенда: стили, раскладка, отрисовка связей |
| `prototype/src/build_stand.py` | Вставляет данные в шаблон, собирает `build/stand.html` |
| `prototype/src/ged2json.py` | Разбор GEDCOM, урезанный JSON для стенда |
| `prototype/data/*.json` | Разобранные роды |

## Что умеет прототип

Пять визуальных направлений, две темы, роли просмотра, линейка дат, выбор стороны основателя, ручной сдвиг человека среди братьев. Раскладка контурная: пара встаёт между крайними детьми, соседние ветки заходят друг под друга там, где силуэты не сталкиваются. Многобрачие показывается уровнями связей, дети группируются по бракам.

Подробности решений — в `docs/decisions.md`.

## Макеты

Хранятся как есть, чтобы можно было вернуться к любому шагу.

| Папка | О чём |
|---|---|
| `mockups/раскладка/` | Варианты раскладки дерева, рабочий экран, переходы между родами |
| `mockups/направления/` | Визуальные направления, темы, фоновые узоры |
| `mockups/связи/` | Отрисовка браков и спусков к детям, повторные браки |

Открываются двойным кликом, интернет нужен только для шрифтов.
