## Дизайн: что осталось

Пять направлений остаются все: это переключаемые стили приложения, а не конкурс с одним победителем. Значит каждая новая деталь делается для всех пяти.

- [x] Один известный родитель: связь выходит сбоку витым завитком, перенесено во все пять стилей.
- [x] **Светлые темы** «Гобелена» и «Ночного кабинета» нарисованы заново: «золотное шитьё» и «зелёная лампа».
- [x] Линейка дат: двойная шкала, ярусы по медиане со сдвигом к своему году, проверено на всех пяти стилях и обоих родах.
- [x] **Линейка дат в светлых темах** — проверена во всех пяти стилях на рабочем приложении: шкала, подписи поколений и выделенный ярус читаются.
- [x] **Метки и портреты.** Портрет-миниатюра и знак метки нарисованы для всех пяти стилей, есть выключатель портретов и фильтр по метке. Хранить метки и снимки пока негде, поэтому видно по адресу с `?demo=marks`.
- [x] **Люди без года.** Порядок среди братьев — по записи семьи, высота на линейке — по оценке по родне. В исходных файлах без года только заглушки, правило проверено снятием годов у настоящих людей.
- [x] **Главенство линии.** Отдельное поле, которое задаёт человек, и отдельный режим просмотра: переключатель «главная линия» в панели, по умолчанию выключен. Включён — пара встаёт над продолжателем (прямой ствол), линия подсвечена нитью акцента, конец без детей помечен знаком «линия пресеклась». Поля в данных пока нет, цепочки видно по адресу с `?demo=marks`.

## Черновики на подумать

Идеи, которые понравились, но пока не нашли места. Образцы — `mockups/направления/метки-по-стилям.html`.

- **Знаки-сноски в газете.** У каждой метки свой типографский знак — †, ‡, §, ¶ — своим цветом после имени. Знаком метки на карточке не взят: спорит с надстрочной римской цифрой очереди брака. Тема интересная — может пригодиться в другом месте газетного стиля.
- **Ярлыки картотеки в ночном кабинете.** Цветные выступы на верхнем крае карточки рядом с ярлыком рода, как разделители в ящике. Очень понравились, но легко спутать с самим ярлыком рода. Основным знаком метки пока выбраны кнопки.
