# Витрина

Показ инструмента без сервера: гость открывает ссылку, и приложение целиком работает у него в браузере — своё дерево, своя правка, свои загрузки. Платить за сервер для этого не нужно.

Адрес: <https://iuchar.github.io/lineage/>

## Как устроено

Ядро — тот же Python, что на настоящем сервере. В браузере его запускает Pyodide: страница берёт с CDN Pyodide 0.28, доставляет `sqlite3` и через `micropip` ставит `fastapi` и `pydantic`.

Само приложение едет архивом `core.zip`: туда кладутся `server/app/**` и четыре рода из `houses/`. Архив собирается на каждой сборке — витрина всегда везёт тот же код, что и сервер, руками ничего не копируется.

Мост (`web/src/api/bridge.ts`) подменяет `fetch`: запросы к `/api/` и `/r/` не уходят в сеть, а вызываются прямо у приложения по ASGI. Ответ не сетевой, поэтому браузер не берёт из него cookie — мост держит их сам, и вход редактора работает как на сервере.

База лежит в самом браузере (IndexedDB через IDBFS), файлы родов — рядом с ней, в `/data/houses`. У каждого гостя свои данные, никуда не уходят. Правка сбрасывается на диск с небольшой задержкой и обязательно при уходе со страницы.

При первом заходе гость видит заставку, роды разворачиваются из архива, а заметка объясняет, что это показ, и даёт имя и пароль редактора.

Замысел и причины решений — `superpowers/specs/2026-09-28-brauzer-design.md`.

## Как обновлять

Ничего запускать не нужно: витрина пересобирается сама при пуше в `main`, если менялись `web/`, `server/app/`, `houses/` или сам рабочий процесс. Ход сборки — вкладка Actions, процесс «Витрина» (`.github/workflows/pages.yml`).

Вручную — кнопка «Run workflow» там же.

Собрать у себя и посмотреть до публикации:

```bash
cd web && npm run build:pages
```

Страница складывается в `docs/витрина/` (в git не попадает). Открывать её файлом нельзя — нужен адрес, иначе браузер не отдаст архив. Проще всего поднять раздачу папок проекта и зайти на `http://localhost:8720/docs/витрина/`:

```bash
uv run --project server python -m http.server 8720 --bind 127.0.0.1
```

## Что помнить

Первый заход у гостя долгий — Pyodide и пакеты тянутся с CDN, это десятки секунд. Дальше браузер берёт их из своего кеша.

Роды на витрине — те, что лежат в `houses/` на момент сборки. Правка в дереве меняет файл рода, и следующая сборка увезёт его гостям.

Данные гостя живут только у него. Общего дерева и ссылок семьям здесь нет: ссылки зрителям показаны устройством, но открыть их некому — это работа настоящего сервера (этап 10).
